
# gitzy (Main Command)

Manage multiple GitHub identities and switch between them easily.

---

## Usage

```bash
gitzy [command] [flags]
```

Gitzy is a cross-platform CLI for managing and switching between multiple GitHub profiles. Use subcommands to add, switch, list, or remove profiles.

---

## Common Options

- `--docs`   Show embedded documentation
- `-h, --help`   Show help for gitzy
