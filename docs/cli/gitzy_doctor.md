
# gitzy doctor

Troubleshooting and diagnostics for Gitzy.

---

## Usage

```bash
gitzy doctor [flags]
```

This command provides troubleshooting information, diagnostics, and embedded documentation to help resolve issues with Gitzy profiles, credential helpers, or configuration.

---

## Options

- `-h, --help`   Show help for doctor
- `--docs`       Show embedded documentation

---

For more help, see the [main documentation](../index.md) or [credential management guide](../credential-helper.md).
